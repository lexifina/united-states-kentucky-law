# Rule 805 Hearsay within hearsay Hearsay included within hearsay is not excluded under the hearsay rule if each part of the
combined statements conforms with an exception to the hearsay rule provided in these rules.
Effective: July 1, 1992
History: Enacted 1990 Ky. Acts ch. 88, sec. 60; renumbered (7/1/92) pursuant to 1992 Ky. Acts ch. 324, sec. 34.
