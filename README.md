# United States (Kentucky): law history in git

Part of [lexifina/global-law](https://github.com/lexifina/global-law), one git history for every country's law: this is the law of Kentucky, United States, which global-law reads at `united-states/kentucky/acts/`.

The law of Kentucky as a git history: one file per provision, with `git blame` and `git log` working line by line. It follows the shared design of [lexifina/global-law](https://github.com/lexifina/global-law).

## Dates

Each new KRS chapter is current consolidated text, labelled oldest version available. Its date is the latest explicit Effective date among current section PDFs, including the latest History entry when no standalone Effective line is printed. The database update day is a currency statement. Explicit future and expired variants are excluded from current wording. The original 60 imported records retain their previously recorded 2026-10-29 dates; these legacy dates await a separate source-date correction. No earlier legal text is reconstructed.

## How it is checked

Every version is read back from git on the day it took effect and on the day before (`tools/check_repo.py`) and must match `corpus.json`; the results are in `REPRODUCE.md`.

## What "author" means

The author of a commit is the law that made the change, with an e-mail address that cannot exist (`<law key>@apps.legislature.ky.gov.invalid`). In this first build no dated history is available, so every commit is credited to the publisher as "oldest version available". The committer is always Lexifina.

## Limits

Coverage is partial: the original Constitution groups and KRS chapters plus the additional chapters listed above. Other KRS chapters, the Acts of the General Assembly, Kentucky Administrative Regulations, and earlier or future wording are not included in this addition. Chapters whose source dates or current variants cannot be resolved are held. Repeal and supersession stubs remain as source notes within operative chapters; chapters containing only such stubs are excluded from current normative coverage.
